## 3. Propuesta HBA, sin aplicar

Archivo `infra/qa/c1.1/pg_hba.conf.propuesta`. Es una plantilla deliberadamente incompleta para tráfico bridge; antes de instalar requiere resolver y renderizar los orígenes autorizados.

Orden propuesto:

1. Socket QA solo bootstrap con SCRAM; rechazar replicación física local y después cualquier otra conexión local. La API no necesita socket. Bootstrap debe tener password SCRAM comprobado antes del corte.
2. Reglas TCP /32 y /128 de loopback interno solo para bootstrap/app sobre QA, con SCRAM. Son útiles para diagnóstico dentro de QA y nunca trust.

Nunca `rejectUnauthorized=false`. Habilitar TLS y observar su resultado constituyen actuación separada; no se dan por hechos.

Reemplazar reglas, no añadir SCRAM debajo de trust. No se conserva trust como vía de recuperación. La recuperación usa sesión administrativa ya abierta y procedimiento externo autorizado.
